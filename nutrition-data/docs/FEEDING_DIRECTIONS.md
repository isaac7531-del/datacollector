# Feeding Directions

Manufacturer feeding directions are extracted into structured rules but are not treated as universal nutritional requirements.

Supported forms:

- grams per 100 kg bodyweight;
- kilograms per horse per day;
- scoops per day;
- maintenance, light, moderate and hard work;
- racing;
- breeding;
- pregnancy;
- lactation;
- youngstock;
- pony;
- senior;
- weight gain;
- weight loss.

Each rule retains:

- original text;
- product ID;
- condition;
- amount range;
- unit;
- source URL;
- confidence.

The recommendation engine can compare these rules against calculated requirements and practical intake limits.
