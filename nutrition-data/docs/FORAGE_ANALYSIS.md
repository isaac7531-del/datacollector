# Forage Analysis

Supported forage sources:

- hay;
- haylage;
- lucerne / alfalfa;
- pasture;
- chaff;
- beet pulp;
- straw;
- custom analyses.

Supported data origins:

- generic regional references;
- laboratory forage tests;
- user-entered analyses.

Supported laboratory import profiles:

- Equi-Analytical;
- Dairy One;
- CVAS;
- Eurofins;
- local forage laboratories.

Supported upload/import forms:

- CSV;
- TSV;
- extracted PDF text;
- plain text;
- administrator-entered manual rows.

Laboratory values override generic estimates for a ration.

Retained fields:

- laboratory;
- sample date;
- dry matter;
- analysis method;
- units;
- document URL;
- confidence.

Generic forage references are low-confidence estimates and must not be presented as precise analyses.
