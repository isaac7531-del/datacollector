# EquiRatings licensing boundary

EquiRatings is not treated as an ordinary federation result source.

## Categories

| Category | Handling |
|---|---|
| Factual competition results | May be ingested only if sourced from authorised/public factual result source or licensed EquiRatings API. |
| Publicly displayed metadata | Link/attribute unless terms permit extraction. |
| Proprietary ratings | Do not ingest without written permission. |
| Proprietary predictions | Do not ingest without written permission. |
| Editorial content | Do not copy into EquiBets data. |
| Derived analytics | Treat as licensed partner data only. |

## API

EquiRatings API documentation indicates JWT-authenticated provider access. A connector may be built only after EquiBets has credentials and licence terms.

## Current status

- Canonical source registered.
- Connector scaffolded.
