# Live source acquisition sources

This folder documents source-specific reconnaissance and connector status.

Source classes:

- Fully automated: ordinary server requests to public pages/files/endpoints, no bypass.
- Browser-assisted: user-controlled browser session reads data already visible to the user.
- File/export-assisted: authorised users upload or supply public exports.
- Unsupported: private, blocked or disallowed acquisition.
